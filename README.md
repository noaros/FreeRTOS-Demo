# FreeRTOS-Demo

This will log my working through the FreeRTOS demo provided that most closely matches my hardware. I have a nucleo STM32F429ZI, and it looks like they have a demo for the 407ZG. Close enough? Let's find out!

Ok so one initial annoyance is the demo project for 'free' FreeRTOS expects a very non free commercial IDE! So much for a smooth start, as first step is now to hack it up into a form I can control. And while I wasn't planning to use Claude Code on this project, since my starting point is already wrong, with a bunch of the wrong kind of files, let's just see what Claude can do. Will give me a chance to get it integrated with VS Code.

Ok I was totally blown away by Claude Code. It did so many things. What amazed me the most is how it sought solutions to the incomplete information I had provided, even going so far as examining other projects I hadn't told it to look at lol, and incorporating aspects into the target project. And finding missing pieces on the internet that matched that code and making scripts to pull it in. Wow. It's results even built. They wouldn't work on the actual board, because even if the solution is correct, Claude itself told me additional changes are needed to adapt to hardware. Still, I have so little clue what it did even after studying its output and changes, that for learning purposes I'm going to throw its results away and manually assemble the RTOS I need. But at this point I don't know if starting with the demo project is even worth it vs scratch.
